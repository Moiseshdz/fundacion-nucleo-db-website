# Fundación Núcleo DB — Sitio Web Institucional

Sitio web institucional desarrollado para **Fundación Núcleo DB A.C.**, con enfoque en presentación corporativa, comunicación de programas, impacto social, galería y navegación responsiva.

## Tecnologías

- PHP
- HTML5
- CSS3
- JavaScript
- Diseño responsivo

## Características

- Página institucional responsiva
- Secciones de misión, programas, impacto, galería y equipo
- Carrusel visual en portada
- Navegación adaptable para dispositivos móviles
- Recursos gráficos optimizados para presentación web
- Diseño orientado a identidad institucional

## Estructura principal

```text
foundation-website/
├── page-fundacion.php
├── style.css
├── imágenes y recursos multimedia
└── README.md
```

## Enfoque de portafolio

Este proyecto demuestra experiencia en desarrollo de sitios institucionales, maquetación web responsiva, diseño visual y organización de contenido corporativo.
